# study27 economy research

**Current outcome: experimental.** The selected second-phase package failed its predeclared fresh confirmation: 521–503 against the cleaned PR11 control, paired-map p = 0.603397; matched five-reference delta +2.23 pp, map-direction p = 0.139357. The positive descriptive scores do not validate a stronger replacement.

The first phase tested 13 isolated and combined banking, recall, and camp policies on a 53-map screen. The camp-focus forecast lost about 31.32 percentage points against the matched reference panel. Code review identified a travel-stall failure mode; the full run was stopped before completing its planned cohort. Retained individual game caches are incomplete-cohort evidence, not a completed 253-map comparison.

The [second phase](v2/README.md) preserved the original plans, frozen modules, and negative evidence, then composed six packages without camp focus. `productive_walk` combines walking-distance banking, reachable camp targets, redundant-capturer evacuation, and travel-aware optional recall. It received 253-map development and exposed 128-map transfer checks before one final source/WASM freeze and a new 512-map cohort. No tuning or alternative-candidate testing followed that final result.
