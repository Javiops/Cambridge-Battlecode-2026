# o92 mcarry: built, NOT measured

Marcella goes first in the carry order on shared rewards: Marcella, then Vesper, then the rest. This replaces P_VCARRY's
Vesper-first order. Variants: 1, and 2 = 1 plus Marcella's no-leave on a waiting reward.

It applies on e85 (gold30-nohold-b35). It is not measured because the site moved to engine 2.0.0 on 2026-10-26, and the
motivating stats were measured on engine 1.0.3 (see the header of `o92_mcarry.py`).
