# GA farm: many machines evolving one bot (island model)

`tools/ga/island.py` runs one **island** of a genetic algorithm. Every machine runs one island: each cloud thread
(4 cores) and the PC (12 jobs). Islands evolve the same genome independently, each with its own seed, scope and
rivals. After every generation they swap their best genomes (**migrants**). This keeps the populations diverse,
spreads good genes to every island, and makes each island's rivals harder over time.

## The genome

One genome covers the whole bot (607 ints patched into one instrumented wasm, magic `GAS1`). The default genome
plays exactly like `bots/study27-economy`.

| family (`--scope`) | genes | file |
|---|---|---|
| `micro` | 22 fight weights (flee/recall %, engage ratio, kite, volley, chase, danger spots) | `genome.py` |
| `structure` | micro rules on/off and their order, 12 fight switches | `structure.py` |
| `macro` | 37 economy genes: tributes, shop, item plan, camp choice and sharing, recall trips, draft, centre hold | `macro.py` |
| `gp` | the evolved "back off" and "engage" conditions (expression trees) | `gp.py` |
| `neat` | an evolved network that picks the action in a fight | `neat.py` |

`--scope all` (the default) mutates everything. An island with `--scope macro` only mutates macro genes, but it can
still take in migrants that differ anywhere.

## How an island scores a candidate

Each generation, the island draws `--maps` fresh maps (10 by default) from 211 training maps: the 17 site maps,
`maps_gen` and `maps_train`. The sealed sets `maps_hold60`, `maps_dev200` and fresh300, and the validation set
`maps_v100`, are excluded.

Every candidate plays every rival on both sides. Fitness is the candidate's margin over the **control** (the
island's start genome, default `ga65a6` = v44 online) on the same games, averaged over every generation it was
evaluated in and shrunk toward 0. This is the same rule as `ga.py` and `sga.py`.

**Rivals:**
- the control itself (`genome:start`)
- the previous online bot (`genome:default`)
- the earlier weight-GA genome `9872f93cac`
- `bots/spar11` and `bots/spar16`
- the **hall of fame**: the best migrant of the 2 most recently active other islands (`--hof 2`)

**Racing:** every candidate plays the first half of the maps. Only the better half, plus the elites, plays the
rest, which saves about 25% of the games (`--race 0.5 --keep 0.5`; `--race 1` turns it off).

## Exchange

```
<farm>/BOARD.md                         one line per island (regenerated by every island)
<farm>/islands/<name>/status.json       generation, games/s, best genome, migrants out/in
<farm>/migrants/<name>/<cid>.json       a migrant: the full genome, base hash, fitness, what it changes
<farm>/islands/<name>/state.json ...    checkpoint (shared-folder islands only): state, games.jsonl, log.md, template.wasm
```

- **Cloud threads** use `--farm /mnt/project-files/ga-farm`. They write their checkpoint there too, so a container
  restart loses at most the generation in progress.
- **The PC** has no shared folder, so it uses the git branch `ga-farm` (`--git-branch ga-farm`). It only pushes
  `migrants/pc/`, `islands/pc/status.json` and `BOARD.md`. Its checkpoint stays on its own disk in `out\islands\pc\`.
- **Bridge:** one cloud island also runs with `--git-branch ga-farm`. It copies the PC's files into the shared
  folder and the cloud islands' files into the branch. With `--git-readonly` it only reads the branch. While the PC
  still runs the old weights GA (`pc_island.py` on branch `pc-island`), the bridge also reads that branch with
  `--legacy-branch pc-island` and turns its best genomes into migrants of island `pc`.

Migrants are only taken from islands with the same base bot (hash of `bots/study27-economy/src`). Each generation
takes in at most `--imports 2` new migrants. A migrant re-earns its fitness on the importing island's own games.

## Cloud thread: run an island

```bash
pip install cambc==2.2.1        # plus the toolchain fetch of harness/README.md if `cambc init` cannot download it
cambc init --yes                # maps/ (17 site maps)
python3 tools/ga/island.py ensure --name cloud-b --farm /mnt/project-files/ga-farm --scope all --jobs 4
```

`ensure` starts `run` in the background unless this island already runs on this host. It resumes from the
checkpoint, so it is also the restart command. Containers restart while a session is idle, so the thread that owns
an island keeps a self-wake every 10-15 minutes (`send_later`) that runs the same `ensure` command.

Other commands use the same `--name` and `--farm`:
- `stop` ends the island.
- `board` reprints the board.
- `validate --top 3` plays the island's best genomes on the 100 v100 maps, with a sign test against the control.
- `export --id CID --out bots/NAME` writes a normal bot folder plus `NAME.json`. Gate it with
  `python3 tools/gate.py bots/NAME bots/study27-economy --kind fight|farm`.

## The PC island (Windows)

One-time setup, in `C:\Users\Javier\Cambc2026\<repo>` (PowerShell; on this PC `python` opens the Store, use `py`):

```powershell
py -m pip install --upgrade cambc==2.2.1          # same engine as the cloud (2.1.6 gives different games)
cambc --version                                   # must say 2.2.1
git fetch origin
git checkout claude/ga-farm-d37xlq                # main once the PR is merged
cambc init --yes                                  # maps\ and the toolchain in %LOCALAPPDATA%\cambc
```

Stop the old weights GA first: create the file `out\ga-pc\STOP` and wait for its generation to end. Then:

```powershell
py tools\ga\island.py ensure --name pc --scope all --git-branch ga-farm --jobs 12
```

- The island runs at below-normal priority (`--low 1`, the default), so the PC stays usable. Use `--low 0` when
  the PC is idle.
- It builds the template once (about 15 s), then plays a generation in roughly 1-2 minutes at 12 jobs.
- After every generation it pushes its migrants and status to `ga-farm` with your normal git credentials.
- Logs are in `out\islands\pc\run.log` (output) and `out\islands\pc\log.md` (one line per generation).
- `struct.patch` is applied with `git apply` when `patch` is missing, with line endings normalised, so autocrlf
  checkouts work.
- The wasmtime compile cache is `out\wasmtime-cache` (set automatically).
- Restart after a reboot with the same `ensure` command. Stop with
  `py tools\ga\island.py stop --name pc --git-branch ga-farm`.

## Checking the farm

`/mnt/project-files/ga-farm/BOARD.md` in the cloud, or `BOARD.md` on the `ga-farm` branch. A genome becomes a
candidate for the site when it leads its island over 5 or more generations. Then run `validate` on v100, `export`
it, gate it with `tools/gate.py`, and record it with `tools/idea.py`. Online tests stay with the online-loop thread.
