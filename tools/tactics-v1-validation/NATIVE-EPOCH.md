# Native stale-epoch regression

Run `run_native_stale_epoch.py --cli PATH --project ARENA --source bots/tactics-v1/src --output NEW_DIRECTORY` with the official SDK 2.2.2 and engine 0.0.2. The runner pins the reviewed SDK and map, preserves the module/replay/statistics, and rejects source changes during validation.

The scripted Ren fixture checks four cases on both sides:

1. A current living owner still selects a legal native dash landing under an explicitly projected awake-camp threat. A fuel guard must not pass by permanently disabling dash.
2. An actual awakened elk kills the real owner. Calling the official SDK `valid_tiles()` on that dead owner must reproduce expected native error 5. This caught negative control is recorded separately from unexpected errors.
3. A saved alive projection with an old owner round must cause the actual escape, combat and optional channel-cancellation helpers to decline before querying the now-dead live ability.
4. A deliberately contradictory alive/current-round projection on the dead owner, with approximately 23,000 fuel remaining, isolates the insufficient-budget guard. It must decline before a native dash mask. This projection is not a valid World snapshot or a model of real death timing.

This tests production helpers with the real SDK, actual camp death, and a native failing control. The threat projections and scripted main do not establish competitive strength, exhaustive yield safety, or an unmodified production-main pass. The report distinguishes expected control error 5 from native faults, unexpected errors and fuel suspensions.
