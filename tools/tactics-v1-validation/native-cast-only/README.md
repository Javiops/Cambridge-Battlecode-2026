# Native safe direct-cast farming

Run `run_native.py --cli PATH_TO_CAMBC --project PATH_TO_ARENA --source PATH_TO_BOT_SRC --output NEW_DIRECTORY --mode MODE` with official CLI/SDK2.2.2 and engine0.0.2. The runner copies requested source into a local guest and records hashes; it never edits the source or game installation.

The original Expanse geometry reproduces an integration20 stall. Actual unupgraded Cassi walks legally to `(58,65)`, four tiles from the singleton Elk `(54,64)`. Native Cassi has700HP,70Focus and a range4 direct spell dealing140 every8 owner turns. The Elk has2400HP,60Strength and range3. Production contains no map-name or coordinate branches.

Modes:

- `mechanics`: the pure scalar certificate predicts18shots/137owners/700remainingHP; a scripted native controller executes exactly that schedule.
- `caller`: the production completed-cycle quote, common typed consumer and mutation gateway select and execute the stationary clear. Every cooldown owner must hold Clear without a basic/AoE substitution.
- `cooldown`: a lawful priming cast plus3 real owner ends yields an initially sleeping2260HP Elk and actual cooldown5. The new job enters a paid stationary Clear hold, then17accepted casts clear it in134owner opportunities, preserving700HP.
- `full-main`: after the lawful movement prelude, only unchanged production `Bot::turn` decides. The runner copies the requested main into `production-main.h`, renaming its outer entrypoint for fixture embedding; it verifies that file hash against the requested production main. It must clear in18casts/137owners, preserve700HP, then capture and complete a36gem bank.

Other bodies idle. No World, mission, stat, HP, wallet, claim or score fields are projected. Original map coordinates and controlled drafting/movement are fixture setup, not autonomous map discovery. These are scoped correctness/activation proofs, not strength benchmarks or guarantees against active enemies. Fresh hostile observations, warnings, changed geometry and actual permissions remain production vetoes.

All modes require zero faults/fuel pauses and the pinned SDK/engine. Source, main, module, map, statistics and replay hashes are retained. `development-*.json` records earlier passing development snapshots and states their limitations; final frozen-source runs are separate. The original `retained-result.json` predates the adapter and only proves mechanics. Its first parser incorrectly expected an A marker although the actor is B; the corrected parser rechecked that retained replay without replaying a game.
